# Install me on Android (beta)
<!-- Nur lokal, nie im Repo: Bild 02 Assets Mia/veil-docs/install-firefox-android.webp (16:9) -->

Firefox for Android, version 128 or newer. Android is in **beta**: I’ve been tested in an Android emulator, and real phones vary. Tell me on [Discord](https://discord.gg/2C8YAwDkat) how it goes.

Firefox for Android only installs files like mine through a hidden menu. Sounds dramatic, takes a minute.

## Get the file

1. In Firefox on your phone, download the newest Firefox file of HYPNOMIA VEIL (it ends in `.xpi`) from [my release page](https://github.com/Hypnomia/hypnomia-veil/releases/latest). It lands in your Downloads.

## Unlock the hidden menu

1. Open the Firefox menu (three dots) and tap **Settings**.
2. Scroll down and tap **About Firefox**.
3. Tap the Firefox logo five times quickly. Firefox says the debug menu is on.
4. Go back to **Settings**. Near the bottom, under **Advanced**, there’s now **Install extension from file**.

## Install me

1. Tap **Install extension from file**.
2. Pick the `.xpi` file from your Downloads.
3. Firefox asks whether to add HYPNOMIA VEIL. Tap **Add**.
4. Firefox says “HYPNOMIA VEIL was added”. Tap **OK**.

My welcome page opens in a new tab: the flashing warning, the age check, then your choice to hand me the reins. Nothing is ticked for you.

## Finding me later

There’s no toolbar icon on Android. Open the Firefox menu (three dots), tap **Extensions**, then **HYPNOMIA VEIL**. My popup opens, with **Pause Mia** at the top and **All settings** for everything else. That’s the way to keep me close on a phone: [Pin me](how-i-work.md#pin-me).

There’s no keyboard shortcut on a phone. Pausing works through that menu. See [Pause](pause.md).

## Good to know

- Firefox updates me by itself, on Android too. See [Updates](updates.md).
- Importing the [Mia Pack](mia-pack.md) works the same as on a computer: the file picker opens your Downloads.
- Can’t find the hidden menu? See the [FAQ](faq.md).
