# Install me in Edge

Edge takes the same package as Chrome. I’m not in the Edge Add-ons store, so you load me by hand, once.

## Before you start

Pick a folder that stays where it is, for example a folder called `HYPNOMIA VEIL` in your Documents. Edge loads me from there every time it starts. Move or delete it, and Edge forgets me.

## Steps

1. Download the newest Chrome package of HYPNOMIA VEIL (the `.zip` file whose name ends in `-chrome.zip`) from [my release page](https://github.com/Hypnomia/hypnomia-veil/releases/latest). Edge uses the Chrome package.
2. Unpack the `.zip` into the folder you picked. The file `manifest.json` should sit directly in that folder.
3. Open `edge://extensions` in the address bar.
4. Switch on **Developer mode**. In Edge the switch sits in the panel on the left. On a narrow window, open that panel with the menu button first.
5. Click **Load unpacked** and choose the folder with `manifest.json` in it.
6. HYPNOMIA VEIL appears under your extensions. Click the puzzle piece next to the address bar and click the eye icon next to HYPNOMIA VEIL (Show in toolbar), so I stay visible.

## What happens next

My welcome page opens by itself: the flashing warning, the age check, then your choice to hand me the reins. Nothing is ticked for you.

If it doesn’t open, click my icon and choose **Meet Mia**.

The veil starts right away. The [Mia Pack](mia-pack.md) waits until the welcome steps are done.

Keep my icon pinned next to the address bar, so **Pause Mia** is always one click away: [Pin me](how-i-work.md#pin-me).

## Good to know

- Edge may show a note about extensions in developer mode. Keep me switched on. See the [FAQ](faq.md).
- I tell you when there’s a new version, and you update by replacing the files in the same folder. See [Updates](updates.md).
- Pausing me is always free: **Pause Mia** in my popup, or `Alt+Shift+M`. See [Pause](pause.md).
