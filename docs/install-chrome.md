# Install me in Chrome
<!-- Nur lokal, nie im Repo: Bild 02 Assets Mia/veil-docs/install-chrome.webp (16:9) -->

I’m not in the Chrome Web Store, so you bring me in by hand. It takes two minutes, and you only do it once.

## Before you start

Pick a home for me first: a folder that stays where it is, for example a folder called `HYPNOMIA VEIL` in your Documents. Chrome loads me from that folder every time it starts. Move or delete it, and Chrome forgets me.

## Steps

1. Download the newest Chrome package of HYPNOMIA VEIL (the `.zip` file whose name ends in `-chrome.zip`) from [my release page](https://github.com/Hypnomia/hypnomia-veil/releases/latest).
2. Unpack the `.zip` into the folder you picked. The file `manifest.json` should sit directly in that folder, not in a folder inside it.
3. Open `chrome://extensions` in the address bar.
4. Switch on **Developer mode** in the top right corner.
5. Click **Load unpacked** and choose the folder with `manifest.json` in it.
6. HYPNOMIA VEIL appears in the list. Click the puzzle piece next to the address bar and pin me, so my popup is one click away.

## What happens next

My welcome page opens by itself. First a warning about flashing, then the age check, then you decide whether to hand me the reins. Nothing there is ticked for you.

If the welcome page doesn’t open, click my icon and choose **Meet Mia**.

The veil works right away. The [Mia Pack](mia-pack.md) comes after the welcome steps.

Keep my icon pinned next to the address bar, so **Pause Mia** is always one click away: [Pin me](how-i-work.md#pin-me).

## Good to know

- Chrome may remind you that an extension runs in developer mode. That’s just how hand-loaded extensions work. See the [FAQ](faq.md).
- Updates don’t install themselves in Chrome. I tell you when there’s a new version. See [Updates](updates.md).
- Pausing me is always free: **Pause Mia** in my popup, or `Alt+Shift+M`. See [Pause](pause.md).
